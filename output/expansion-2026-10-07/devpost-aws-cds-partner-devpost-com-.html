Calling all AWS Partners! We are inviting you to build the next wave of conversational solutions on AWS Communication Developer Services (CDS)! AWS CDS enables AWS Partners to help customers engage users at a global scale through AWS End User Messaging (EUM) which includes Rich Communication Services (RCS), Short Message Services (SMS), and WhatsApp. It also includes Amazon Simple Email Service (SES). AWS CDS is the infrastructure that powers messaging across Amazon.com, Amazon Cognito, SNS, and Amazon Connect.

AWS CDS is often used for one-time passwords (OTP), notifications, and rules-based chatbots that follow rigid scripts. We challenge you to think beyond this. The future of customer engagement is conversational: reaching customers in the channel (i.e. email vs. RCS vs. WhatsApp) they prefer, picking up right where the last conversation left off, and using two-way communication so customers tell you directly what they want and share signals that improve your products and services.

Picture omnichannel experiences where a conversation starts in one channel and completes an action in another: a prescription refill reminder via SMS that lets the patient find and schedule the nearest pharmacy pickup through RCS with a tap, then sends dosage instructions via email, all without leaving the messaging experience.

Push the boundaries. Build agentic solutions where AWS CDS is the communications backbone, powered by AI such as Amazon Bedrock AgentCore.

Surprise us with your real customer and industry solutions!

Why You Should Participate

  • Innovate with AWS CDS. Get hands-on with AWS CDS combined with agentic AI powered by Amazon Bedrock AgentCore.
  • Solve Real Customer Problems. Create agentic solutions tied to customer and industry use cases that can scale across your customer base. Package your hackathon submission into a repeatable offering, list it on AWS Marketplace, and win AWS Specialist GTM and enablement support to accelerate real customer deals.
  • Win Big. Compete for your share of $40,000 USD in cash prizes, in addition to an opportunity for a joint case study and 1:1 access to AWS Specialists to build and grow your AWS CDS practice and hackathon solution.
  • Visibility for Your Organization. Winners will be announced via Devpost and the top winner will be offered a joint case study with AWS. Drive awareness and new leads to your practice.
  • Direct Access to AWS Specialists. Join live webinars and weekly office hours to ask questions, get feedback, and shape the services roadmap.

How to Get Started Now

  • Brainstorm Your Idea. Think outside the box to improve customer communication experience through AWS CDS.
  • Review the Tech Stack. Familiarize yourself with the AWS CDS services and how to pair them with agentic AI frameworks such as Amazon Bedrock AgentCore. See the Requirements below.
  • Form Your Team (Optional). Find collaborators within the same AWS Partner organization who are excited to improve customer problems through AWS CDS. Diverse skillsets in development, architecture, and customer engagement can go a long way.
  • Start Building. Stand up an RCS agent within 5 minutes to develop an entire solution, decide later to use RCS or phone numbers for each country you’re serving, and expand from there. 

Requirements

What to Build

Entrants must build, develop, and deploy an AI solution on AWS to address a real-world customer use-case that uses at least one AWS Communication Developer Service (CDS) (each a “Project”):

  • AWS End User Messaging (EUM) that includes Rich Communication Services (RCS) and Short Message Service (SMS)
  • AWS End User Messaging Social (WhatsApp)
  • Amazon Simple Email Service (SES)
  • Recommended but not required: Incorporate Amazon Bedrock AgentCore to combine for an agentic AI powered solution. AWS End User Messaging Push does not count as CDS usage for eligibility.

Functionality: The Project must be capable of being successfully installed and running consistently on the platform for which it is intended and must function as depicted in the video and/or expressed in the text description.

We will provide $50 in AWS Credits (1 per team) on a first come, first serve basis to support build cost. We will also provide Kiro access codes for participants (1 per individual) on a first come, first serve basis to support build cost. Refer to the FAQ page for code request form. 

What to Submit

Include a Project built with the required developer tools and meets the above Project Requirements.

  1. URL to your private or public code repository for judging and testing on either GitHub or GitLab. It must contain all source code, assets, and instructions needed for the project to run, and must demonstrate the use of AWS Communication Developer Services at runtime in your code. The repository may be public or private. If the repository is public, the repository must be open source by including an open source license file. This license should be detectable and visible at the top of the repository page (in the About section). If the repository is private, share it with testing@devpost.com and aws-cds-partner@amazon.com. More information provided in this GitHub README.
  2. Architecture Diagram
  3. Text description.
  4. ~3- minute demonstration video of your Project.
  5. URL to your deployed project or instructions on how to interact with it, if not a web application.
  6. Created opportunity ID through AWS Partner Central’s AWS Customer Engagement (ACE). It must include the Marketing Campaign code "AWS CDS Agentic AI Hackathon -Sept. 2026." See FAQ page on how to create an opportunity in ACE.
